# Text To Avatar

## Ziel

Konkreter [Social-Content-Workflowvertrag](Social_Avatar_Content.md) und
[Tool-/Lizenz-/Ressourcenleitfaden](../../media_studio/SOCIAL_AVATAR_AUTOMATION.md). Vorlage ist
planned, keine direkt ausfuehrbare Avatar-Pipeline. Workflow-Vorlage fuer text to avatar.

## Ablauf

1. Eingabe validieren.
2. Rolle/Profil waehlen.
3. Ressourcenklasse pruefen.
4. Leichte Schritte lokal ausfuehren oder schwere Schritte als Queue-Job planen.
5. Ergebnis manuell pruefen.
6. KI-Kennzeichnung und Rechtepruefung dokumentieren.

## Sicherheit

Keine automatische Veroeffentlichung, keine Nachbildung echter Personen ohne Einwilligung, keine
Rohdaten im Repo.
