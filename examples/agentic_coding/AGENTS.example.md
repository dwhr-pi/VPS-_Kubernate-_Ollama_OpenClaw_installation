# Beispiel fuer Projektanweisungen

Nur als bewusst angepasste Anleitung verwenden, nicht ungeprueft als globale Agentenfreigabe
uebernehmen. Diese Datei ist keine Sandbox oder Rechteverwaltung.

1. Erst TASK.md, vorhandenen Code und Tests lesen; Plan vorlegen.
2. Nur benannte Dateien im freigegebenen Projekt bearbeiten.
3. Befehle, Paketinstallation und Netzwerk separat genehmigen lassen.
4. Keine Tokens/Wallets/Produktionsdaten oder private Log-Inhalte lesen/ausgeben.
5. Nach maximal drei Korrekturrunden oder bei Blocker stoppen.
6. Sicherheits-/Abnahmetests nicht abschwaechen. Keine fremden Aenderungen verwerfen.
7. Echte Testausgabe und verbleibende Risiken ehrlich berichten.
8. Commit, Push, PR und Deployment nicht automatisch ausfuehren.
